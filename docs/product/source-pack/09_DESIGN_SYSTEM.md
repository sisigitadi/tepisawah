# Design System — Tepi Sawah v1

## Design source
Google Stitch is the primary visual exploration/reference tool.

## Public website
Characteristics:
- photography-led
- natural
- warm
- spacious
- strong food imagery
- clear CTA
- premium but approachable

## Customer ordering
Characteristics:
- mobile-first
- thumb-friendly controls
- large food images
- clear price
- simple category navigation
- persistent cart
- minimal text

## POS
Characteristics:
- operational
- high contrast
- clear status
- large action buttons
- low animation
- keyboard/mouse friendly where applicable

## Kitchen
Characteristics:
- large cards
- strong status hierarchy
- minimal navigation
- quick state transitions
- readable from a working distance

## Shared components
- Button
- Input
- Select
- Modal
- Drawer
- Card
- Badge
- Toast
- Tabs
- Table
- Empty state
- Loading state
- Error state
- Confirmation dialog

## Visual tokens
Do not hardcode final colors/fonts from assumptions. Extract approved values from the Stitch design before production implementation.

Required token groups:
- colors
- typography
- spacing
- radius
- shadow
- border
- breakpoints
- motion
