# Feature Matrix

## MVP — Must Have
- Public website
- Menu catalog
- Table QR
- Customer ordering
- Cart
- Order submission
- Cashier confirmation
- Kitchen display
- Waiter interface
- Basic payment recording
- Basic receipt
- Table management
- Menu management
- Role-based access
- Basic dashboard

## MVP+ — Should Have
- Promo engine
- Customer notes
- Call waiter
- Basic sales report
- Daily closing
- Export transaction data

## Later
- Inventory
- Recipe/BOM
- Supplier
- Purchase
- Expense
- Accounting
- Reservation
- Loyalty
- CRM
- Multi-branch
- Automated QRIS
- Advanced analytics
- AI recommendations

## Prioritization principle
A feature is prioritized when it directly reduces operational friction, improves order accuracy, or creates measurable business value.
