# ADR-1: Monorepo with pnpm workspaces

- Status: Proposed
- Date: 2026-09-28

## Context

Six apps (web, order, pos, kitchen, waiter, admin) and ten shared packages must share types, permissions and UI primitives without diverging. A monorepo keeps the contract surfaces single-sourced and lets every app build independently.
